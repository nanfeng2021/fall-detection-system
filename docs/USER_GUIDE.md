## 🎛️ 侧边栏操作

### 1️⃣ 系统控制（最重要！）

```
┌─────────────────────┐
│ ▶️ 启动   ⏹️ 停止    │  ← 点击"启动"开始实时检测
├─────────────────────┤
│      🔄 重置         │  ← 清空所有数据和状态
└─────────────────────┘
```

**操作步骤**:
1. 点击 **"▶️ 启动"** 按钮
2. 系统开始实时处理（模拟数据或真实相机）
3. 看到 "🟢 运行中" 状态表示成功
4. 点击 **"⏹️ 停止"** 暂停检测
5. 点击 **"🔄 重置"** 清空所有数据

---

### 2️⃣ 参数配置

```
┌─────────────────────────┐
│ 体素尺寸 (m)            │
│ ├──●─────────┤ 0.05     │  ← 拖动滑块调整
├─────────────────────────┤
│ 高度骤降阈值 (m)        │
│ ├───●────────┤ 0.3      │
├─────────────────────────┤
│ 速度阈值 (m/s)          │
│ ├───●────────┤ 0.5      │
├─────────────────────────┤
│ 确认帧数                │
│ ────●────────┤ 2        │
├─────────────────────────┤
│ 帧率 (FPS)              │
│ ──────●──────┤ 30       │
├─────────────────────────┤
│   [💾 保存配置]          │  ← 调整后点击保存
└─────────────────────────┘
```

**参数说明**:

| 参数 | 作用 | 调低效果 | 调高效果 | 推荐值 |
|------|------|----------|----------|--------|
| **体素尺寸** | 点云精度 | 更精细但慢 | 更粗糙但快 | 0.05-0.1 |
| **高度骤降阈值** | 摔倒灵敏度 | 更敏感（多报） | 更严格（少报） | 0.3-0.5 |
| **速度阈值** | 下落速度要求 | 更容易触发 | 更难触发 | 0.5-1.0 |
| **确认帧数** | 连续确认次数 | 更快报警 | 更准确 | 2-3 |
| **帧率** | 处理速度 | 更流畅 | 更卡顿 | 30 |

**调整建议**:
- **老年人场景**: 降低高度阈值 (0.3)，减少确认帧数 (2)
- **儿童场景**: 提高高度阈值 (0.5)，增加确认帧数 (5)
- **性能优先**: 增大体素尺寸 (0.1)，降低帧率 (20)

## 💡 常用技巧

### 技巧 1: 快速测试不同场景

在侧边栏调整参数后：
1. 点击 "💾 保存配置"
2. 系统自动重启应用新参数
3. 立即看到效果变化

### 技巧 2: 查看特定时间的报警

在 "报警历史" 页面：
1. 使用浏览器的搜索功能 (Ctrl+F)
2. 搜索时间点或关键词
3. 快速定位目标报警

### 技巧 3: 性能优化

如果 FPS < 20：
1. 增大 "体素尺寸" (0.05 → 0.1)
2. 降低 "帧率" (30 → 20)
3. 减少点云密度

### 技巧 4: 减少误报

如果误报太多：
1. 提高 "高度骤降阈值" (0.3 → 0.5)
2. 提高 "速度阈值" (0.5 → 1.0)
3. 增加 "确认帧数" (2 → 5)

### 技巧 5: 提高灵敏度

如果漏报：
1. 降低 "高度骤降阈值" (0.5 → 0.3)
2. 降低 "速度阈值" (1.0 → 0.5)
3. 减少 "确认帧数" (5 → 2)

## 🐛 常见问题

### Q1: 点击"启动"没反应？

**A**: 
1. 检查浏览器控制台是否有错误 (F12)
2. 刷新页面重试
3. 清除浏览器缓存

### Q2: 点云显示空白？

**A**:
1. 确认已点击 "▶️ 启动"
2. 检查 "系统状态" 是否显示 🟢
3. 点击 "🔄 重置" 重新开始

### Q3: FPS 很低怎么办？

**A**:
1. 增大体素尺寸 (0.05 → 0.1)
2. 降低帧率设置 (30 → 20)
3. 关闭其他占用 CPU 的程序

### Q4: 一直没有报警？

**A**:
1. 等待模拟摔倒发生（约 50 帧后）
2. 降低检测阈值（更敏感）
3. 检查参数是否过于严格

### Q5: 如何保存配置？

**A**:
1. 调整参数后点击 "💾 保存配置"
2. 配置文件保存在 `config.json`
3. 下次启动自动加载
