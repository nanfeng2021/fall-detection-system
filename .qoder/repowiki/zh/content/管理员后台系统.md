## 项目概述

GuardianFall是一个基于3D视觉的室内人体摔倒实时预警系统，专为独居老人家庭、医院病房、养老院等场景设计。系统采用激光雷达/ToF深度相机结合AI算法，提供高精度的摔倒检测和实时报警功能。

### 核心特性

- **隐私保护**：仅获取3D点云数据，不拍摄图像
- **实时检测**：端到端延迟小于3秒
- **高精度**：准确率>95%，误报率<5%
- **全天候工作**：不受光线影响，24小时正常工作
- **AI驱动**：基于规则引擎+深度学习的混合算法

### 技术架构

- **启用**：激活已禁用的账户

4. **验证规则**：用户名唯一、邮箱唯一且格式正确、密码长度至少6位、两次密码输入一致

## 安全机制

### 认证与授权

系统采用JWT Token进行用户认证，支持多层安全机制：

```mermaid
flowchart TD
Login[用户登录] --> Validate[验证凭据]
Validate --> CheckLock{账户锁定?}
CheckLock --> |是| LockError[账户被锁定]
CheckLock --> |否| HashPass[验证密码哈希]
HashPass --> PassCheck{密码正确?}
PassCheck --> |否| RecordAttempt[记录失败尝试]
PassCheck --> |是| Check2FA{需要2FA?}
Check2FA --> |是| Verify2FA[验证2FA代码]
Check2FA --> |否| CreateToken[生成JWT Token]
Verify2FA --> VerifyResult{2FA验证?}
VerifyResult --> |失败| Fail2FA[2FA验证失败]
VerifyResult --> |成功| CreateToken
RecordAttempt --> LockCheck{达到锁定阈值?}
LockCheck --> |是| LockAccount[锁定账户]
LockCheck --> |否| Retry[允许重试]
CreateToken --> Success[登录成功]
LockError --> End[结束]
Fail2FA --> End
LockAccount --> End
Retry --> Login
Success --> End
```

from src.auth.models import RegisterRequest, UserRole

auth = AuthService()

    {"username": "user1", "email": "user1@example.com"},
